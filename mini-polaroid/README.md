# 미니폴라로이드 인쇄

사진을 폴라로이드 모양으로 4×6 인치 한 장에 모아 인쇄하는 PWA. 설치 없이 "홈 화면에 추가"로 사용.

## 로컬 실행
```bash
npm install
npm run dev
```

## 배포 (Netlify)
1. 이 저장소를 Netlify 에 연결. 루트의 `netlify.toml` 이 `mini-polaroid/` 를 base 로 빌드함.
2. 환경변수 없음. 배포 후 HTTPS 주소로 접속 → 홈 화면에 추가.

## 데이터
서버·계정 없음. 사진은 폰 안에서만 처리되고, 완성된 시트 JPEG 는 저장/인쇄 시 이 기기의 IndexedDB 에 최근 20개까지 자동 보관됨.

## 아이폰에서 시작하기
1. Safari 로 배포 주소 접속.
2. 하단 공유(⬆) → "홈 화면에 추가".
3. 홈 화면 아이콘으로 실행 → 사진 고르기 → 장수 선택 → "사진앱에 저장 / 공유".
친구도 같은 주소를 열어 같은 방법으로 추가하면 됨(설치 파일·계정 없음).
